# Дизайн-токены

Источник: Figma-файл «Vanya's Portfolio», страница «Page 1», фрейм «Desktop - 1» (1440×1024).
Именованных стилей (color/text styles) и layout grid в файле нет, значения сняты с узлов через REST API.
Выгрузка: `node design/scripts/figma.mjs check | dump | export` (токен читается из `../.env.figma`).

Файлы:
- `frames/desktop-1440.png` — экспорт фрейма, scale 2. Фрейм обрезан по высоте 1024: карточка «Достижения» продолжается ниже.
- `icons/globe.svg` — иконка у города (24×24, обводка 1px).

Мобильного макета нет, правила адаптации описаны ниже и выведены из десктопа.

## Цвета

| Токен              | Значение               | Где                                      |
|--------------------|------------------------|------------------------------------------|
| `--color-bg`       | `#171717`              | фон страницы, «дырки» между карточками   |
| `--color-surface`  | `#ffffff`              | карточки                                 |
| `--color-text`     | `#282828`              | весь текст, иконка                       |
| `--color-muted`    | `#282828` @ 50%        | подписи, годы (`rgb(40 40 40 / .5)`)     |
| `--color-thumb`    | `#313131`              | плейсхолдер превью проекта               |
| `--color-tag`      | `#282828` @ 6%         | фон тегов технологий (не из макета)      |
| `--color-frame`    | `#282828` @ 12%        | рамка 1px у скриншотов, чтобы белое не сливалось с карточкой (не из макета) |

Тень, градиенты, обводки у карточек отсутствуют.

## Типографика

Один шрифт: **Source Code Pro** (моноширинный, Google Fonts, есть кириллица). Начертания 400 и 500.
Межстрочный интервал в макете 97% от кегля (почти «впритык»), трекинг −4% от кегля.

| Токен            | Кегль | Вес | line-height | letter-spacing | Где                                   |
|------------------|-------|-----|-------------|----------------|---------------------------------------|
| `--text-title`   | 20px  | 500 | 0.97        | −0.04em (−0.8) | приветствие, заголовки разделов, названия проектов и достижений |
| `--text-nav`     | 16px  | 500 | normal      | 0              | ссылки GITHUB / TELEGRAM              |
| `--text-meta`    | 16px  | 500 | 0.97        | −0.04em        | город (MOSCOW)                        |
| `--text-body`    | 16px  | 400 | 0.97        | −0.04em        | описание достижения (muted)           |
| `--text-sub`     | 15px  | 400 | 0.97        | −0.04em        | подзаголовок проекта (muted)          |
| `--text-caption` | 12px  | 400 | 0.97        | −0.04em        | год достижения (muted)                |

Заголовки разделов набраны капсом («ПРОЕКТЫ», «ДОСТИЖЕНИЯ»). В разметке хранить обычный текст и делать `text-transform: uppercase`.
Ссылки в шапке и город тоже капсом.

Примечание: в PNG-экспорте заголовки разделов выглядят у́же остального текста, хотя в узлах указан тот же Source Code Pro 500, без переопределений. Похоже на особенность рендера Figma. На сайте везде Source Code Pro.

Для многострочного текста (приветствие, длинные названия на мобиле) 0.97 слишком плотно; предлагаю 1.2 для абзацев с переносом и 0.97 только для однострочных подписей. Сверить визуально со скриншотом.

## Сетка и размеры (десктоп)

- Колонка контента: одна, **528px**, по центру (в 1440 отступ 456 слева и справа).
- Отступ сверху до первой карточки: 39px.
- Скругление карточек: **15px**. Превью проекта: 64×64, скругление **7px**.
- Внутренние отступы карточки: слева/справа **16px**; сверху 16px (шапка) или **20px** (разделы); снизу ~20px.
- Расстояние между карточками: **17px** (там стоят соединители, см. ниже).

### Карточка 1: шапка (hero)
- Высота в макете 304px. Ссылки сверху, приветствие прижато к низу (отступ снизу 20px). Между ними пусто: шапка — это «обложка».
- Слева ссылки в ряд с gap **16px**. Справа иконка-глобус 24px + город, gap **8px**, по вертикали по центру.
- Приветствие — `--text-title`, ширина на всю карточку, переносится само (в макете 3 строки на 496px).
- В Figma есть скрытый пункт «OTHER LINKS»: место под дополнительные ссылки.

### Карточка 2: «Проекты»
- Заголовок раздела, ниже на 18px список.
- Строка проекта: превью 64×64 + блок текста, gap **12px**, выравнивание по центру по вертикали. Между строками **16px**.
- Блок текста: название (`--text-title`) и под ним краткое описание (`--text-sub`, muted), gap **8px**.
- Левый край текста: 76px от края карточки (16 + 64 + 12). На этой же линии стоит текст в «Достижениях».

### Карточка 3: «Достижения»
- Заголовок, ниже на 14px список, сгруппированный по годам.
- Две колонки: год (`--text-caption`, muted) с левого края контента; записи с отступа 76px (та же линия, что у проектов).
- Внутри года записи идут с gap **20px**; запись — название (`--text-title`) + описание (`--text-body`, muted), gap **4px**.
- Между группами годов ~**50px**.

### Соединители между карточками
Фирменная деталь: карточки не просто стоят столбиком, а «сшиты» перемычкой, как звенья ленты.
В зазоре 17px между карточками:
- белая перемычка от 83px до 445px по ширине карточки (отступ **83px** с каждой стороны, ширина 362 из 528);
- концы перемычки «вырезаны» двумя пилюлями цвета фона: 53×17, радиус 9 (полностью скруглённые), с отступом **39px** от краёв карточки (левая — 39…92, правая — 436…489).

Итого в зазоре слева направо: фон → пилюля фона → белая перемычка → пилюля фона → фон. Пилюли заходят на углы перемычки, поэтому её края получаются вогнутыми.
Делать в CSS (псевдоэлементы у карточки: белый прямоугольник + две пилюли цвета фона поверх) или одним inline-SVG; от высоты контента не зависит.

## Адаптация под мобильные (макета нет — решение по аналогии)

- Брейкпоинт: ширина экрана < 560px (528 + 2×16).
- Карточки на всю ширину минус поля **16px** с каждой стороны; отступ сверху 16px.
- Внутренние отступы карточек, скругления, кегли — без изменений: 20px моно на 343px (ширина 375) даёт ~27 символов в строке, читается.
- Соединители: пилюли 53×17 оставить фиксированными и на тех же 39px от краёв; перемычка — между пилюлями. На 343px они не пересекаются.
- Шапка: вместо фиксированных 304px — `min-height` ~240px; ссылки и город остаются в одной строке, при нехватке места город переносится вниз.
- Проекты: превью 64px оставить, название и описание переносятся.
- Достижения: колонку года сузить до ширины года (~44px) и сдвинуть записи, либо ставить год строкой над группой, если записи начнут переноситься слишком часто. Начать с узкой колонки.

## Дополнения, которых нет в макете

Решения по аналогии со стилем макета, при появлении в Figma заменить.

- **Ссылка на резюме** — третий пункт в ряду ссылок шапки (GITHUB · TELEGRAM · РЕЗЮМЕ), тот же стиль `--text-nav`. В макете под это есть скрытый слот «OTHER LINKS».
- **Теги технологий проекта** — строка под кратким описанием, отступ сверху 8px:
  - `--text-caption` (12px, 400, трекинг −4%), цвет `--color-text`;
  - фон `--color-tag` = `#282828` @ 6% (`rgb(40 40 40 / .06)`), padding 3px 6px, скругление 4px (меньше, чем у превью — 7px);
  - gap 4px, переносятся на новую строку.
  Превью 64×64 при этом выравнивается по верху строки, а не по центру, иначе при 2 строках тегов оно «плавает».

## Порядок разделов

1. Шапка: ссылки (GitHub, Telegram, Резюме), город, приветствие.
2. Проекты.
3. Достижения (по годам, свежие сверху).

Образования и стека на сайте нет: они в резюме.
